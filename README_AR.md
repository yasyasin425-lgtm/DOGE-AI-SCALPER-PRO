# DOGE AI SCALPER PRO — النسخة التجريبية

## ما الذي تفعله هذه النسخة؟
- تجلب شموع DOGEUSDT العامة من Binance.
- تحسب EMA 9/21 و RSI و MACD و ATR ومتوسط الحجم.
- تستخدم إطار 1 دقيقة للدخول وإطار 5 دقائق لتأكيد الاتجاه.
- تسجل محاكاة شراء/بيع في ملف JSON محلي.
- تعرض لوحة تحكم عبر Streamlit.

## مهم جداً
هذه **محاكاة فقط**. لا يوجد اتصال تداول خاص ولا تنفيذ أوامر حقيقية ولا حاجة إلى API Key أو Secret.
لا تعتبر نتائج المحاكاة توصية استثمارية أو ضماناً للربح. رسوم التداول الفعلية تختلف حسب حسابك ومستوى الرسوم والخصومات. الرسوم الافتراضية هنا 0.1% لكل جهة لأغراض الاختبار فقط.
الضغط على تحديث البيانات ينفذ دورة محاكاة واحدة؛ هذه النسخة ليست خدمة تعمل تلقائياً 24/7.

## تشغيل محلياً
1. ثبّت Python 3.10 أو أحدث.
2. افتح مجلد المشروع في بيئة Python.
3. نفّذ:
   ```bash
   pip install -r requirements.txt
   streamlit run app.py
   ```
4. افتح الرابط المحلي الذي يظهر.

## تشغيل من الهاتف
يمكن رفع ملفات المشروع إلى مستودع GitHub من متصفح الهاتف، ثم نشره كتطبيق Streamlit Community Cloud إن كان متاحاً لحسابك. اجعل الملف الرئيسي `app.py`، ولا تضف أي مفاتيح Binance. خدمات الاستضافة المجانية قد تتوقف أو تدخل في وضع السكون؛ لا تضمن التشغيل المستمر.
